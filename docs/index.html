Smart Excel AI Automation Assistant

B.Tech Computer Science / Artificial Intelligence Student Capstone Project

Problem Statement

Manually editing, validating, and analyzing large Excel workbooks is time-consuming and prone to costly human errors. Users often spend hours navigating through rows and columns to update specific values or build custom machine learning models.

Architecture & Modular Design

Module 1: AI Excel Navigator & Updater

Employs natural language intent classification (UPDATE, FIND, CLEAN, ANALYZE, PREDICT), TF-IDF vectorization, cosine similarity, and fuzzy string matching to resolve target columns and rows automatically. Generates diff previews and applies non-destructive edits.

Module 2: Intelligent Data Cleaner

Identifies missing values, duplicate rows, whitespace irregularities, mixed capitalization, and numerical multivariate outliers using Scikit-Learn's Isolation Forest algorithm.

Module 3: ML Analyzer & Predictor

Performs automated feature profiling, correlation analysis, and trains machine learning pipelines (Linear Regression, Logistic Regression, Random Forest) with $R^2$, $RMSE$, $MAE$, and $Accuracy$ metrics.

Technology Stack

Python 3.13 FastAPI Pandas Scikit-Learn NLTK OpenPyXL Isolation Forest HTML5 / Vanilla CSS3 / JS Chart.js & SheetJS GitHub Pages
